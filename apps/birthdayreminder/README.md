# Birthday Reminder privacy policy

The published policy is [`privacy-policy.html`](./privacy-policy.html).

Before submitting the app, keep the policy and Play Console Data safety form synchronized with the released build. In particular, this app uses Google Mobile Ads, Firebase Authentication, and Cloud Firestore when the user enables sign-in/backup.

The account-deletion email route in the policy must remain functional. Google Play also requires an in-app account-deletion path for apps that allow account creation; add and test that path before release if it is not already present in the production build.
